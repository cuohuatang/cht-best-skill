# 提示词资产 · 决策关（Decision Gate）

> 两条高含金量提示词的**合并版**：先发现被绕开的真问题，再对真问题做正反裁决与反转条件监控。
> 归属：`cht-best-skill` V0.0.7 **按触发条件启用的决策关**（不新增第八层、不做每次必过的闸门）。
> 配套：`python3 scripts/decision.py scan / init / verify`。

## 原提示词（保留）

**① 自我觉察卡点**
> 在我们反复讨论过的所有问题中，有没有一个更深层次的问题，是我一直在绕着它走，但一直没有真正问出口的？

**② 重大决策**
> 请全面化身为反方论证专家、决策漏洞审查员和中立裁判，针对我现在倾向做出的决定：
> 第一阶段，禁止支持我，请用最强反方立场尽可能证明这个决定可能是错的，重点找出我遗漏的事实、过度乐观假设、不可逆成本、机会成本、最坏风险，还有情绪带来的认知偏差。
> 第二阶段，切换支持视角，列出该决定能够成立的核心理由。
> 第三阶段，作为中立裁判，对比正反双方关键证据，直接告诉我哪边占优势、最大未知风险，以及出现哪些条件时结论会反转；不要刻意平衡观点，拒绝强行五五开。

## 合并后可直接粘贴的主提示词

```
先别急着给建议，按决策关跑一遍，全程只给可核验条目，不要写"作为某某专家我认为"。

S0 元层回看：先扫我们落盘的历史（agent-tasks/*/progress.md 的决策记录、findings.md 的 [假设] 条目），
   找出反复被否掉、反复返工、反复出现的假设；回答：有没有一个更深的问题是我一直绕着走、没问出口的？
   如果真问题变了，直接说当前任务该「继续 / 重构目标 / 终止」，并写明要回写 task_plan 的哪一处。

S1 反方位（禁止支持我，只许反驳）：用最强反方立场证明这个决定可能是错的，逐条写清
   遗漏的事实 / 过度乐观假设 / 不可逆成本 / 机会成本 / 最坏风险 / 情绪带来的认知偏差。
   本阶段不允许出现任何支持性语句。

S2 支持位：切换视角，列出该决定能够成立的核心理由，每条要带依据。

S3 裁判位：对比正反双方关键证据，直接给「哪边证据占优」的明确判断（反方 / 支持 / 需补证据 / 暂缓），
   写出最大未知风险；不要刻意平衡观点，禁止五五开、各有道理、难分伯仲这类和稀泥表述。
   注意：你给的是证据优势判断，不是替我拍板——决断权在我。

R 反转条件：列出可观测的反转条件——「当 X 出现时，结论应反转为 Y」，
   并写明怎么监控（定时检查 / 哪个数据源 / 什么阈值），条件命中时主动提醒我。
```

## 短版

```
先回看历史：有没有我一直没问出口的真问题？然后三阶段裁决：① 禁支持，只找遗漏事实/乐观假设/不可逆成本/机会成本/最坏风险/情绪偏差 ② 支持理由 ③ 裁判直接说哪边证据占优 + 最大未知风险，不许五五开；最后给「当 X 出现时结论反转为 Y」和监控方式。只给证据优势判断，不替我拍板。
```

## 触发门槛（默认不启用，宁可少用）

满足任一才跑，**消除档 / 轻量档一律跳过**：

- 不可逆成本高：对外承诺、发版、花钱、删数据、签约
- 跨会话反复讨论 ≥2 次，或同一问题返工 ≥2 次
- 你明确说「我在纠结 / 要不要 / 总觉得哪里不对 / 又绕回来了」
- 方向性选择（做不做、选哪条路），而非执行细节

## 两条红线

> **① 论证位 ≠ 人设**（与 V0.0.3「不设角色」、V0.0.4「不演专家」、V0.0.5「职责契约≠人设」、V0.0.6「审查镜头≠人设」同源，第四次复用）：
> 「反方论证专家 / 决策漏洞审查员 / 中立裁判」是**三个论证位的输出契约**，不是抬高权威的形容词人设。
> 这条提示词自带的「禁止支持我」「拒绝强行五五开」恰恰是在**压** AI 的讨好属性，和黄仁勋法同一战线。招的是位子，不是演员。

> **② 证据优势判断 ≠ 替人拍板**（与心法 10、辩论层「裁决权在人」的调和）：
> V0.0.3 要求人自己筛选提炼、保持中立不偏袒；本关要求 AI **给出哪边证据占优的明确倾向**。
> 差异是真的，不能糊弄：AI 输出的是**证据优势判断 + 最大未知风险 + 反转条件**，最终决定仍由人做。

## 输出必须落到 `progress.md`「决策关」区块

```bash
P=~/.codebuddy/skills/cht-best-skill/scripts
python3 $P/decision.py scan "<agent-tasks 的父目录>"   # S0 的素材
python3 $P/decision.py init "<本任务目录>"             # 追加决策关区块（幂等）
python3 $P/decision.py verify "<本任务目录>" --required || exit 1
```

五段缺一不可：**S0 元层回看 / S1 反方位（六项，禁支持性措辞）/ S2 支持位 / S3 裁判位（禁和稀泥、须给明确倾向）/ R 反转条件与监控**。
区块不存在时 `verify` 默认放行（视为未启用）；显式声明高利害决策时加 `--required`，缺区块即阻断。
