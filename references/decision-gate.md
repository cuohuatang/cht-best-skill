# 决策关（Decision Gate · V0.0.7 详解）

> 两条提示词的合并落点：**先发现被绕开的真问题（选对题），再对真问题做正反裁决与反转条件监控（做对决定）**。
> **它不是第八层，也不是第六道「每次必过」的闸门**——是一次按高利害分叉点触发的决策关，插在执行循环 0.3 / 4.5 步，不计入 ≤5 基元。

---

## 1. 为什么合并，而不是加两层

```
提示词 1：我是不是一直在绕着一个没问出口的真问题？   → 选对题
                        ↓
提示词 2：那这个决定到底该不该做、什么时候会翻盘？   → 做对决定
```

分开落地会长成第 5、第 6 道闸门（现有：野心 / 团队 / clarify / council）。加上前置步骤共 6 道，**流程比活还重**，直接违反 M1 消除档与心法 06「别拿琐碎确认打断人」——也和 V0.0.5「不是一个壳」反向。

所以合并成一个**默认关闭、按需开火**的扳机：把三文件记忆、辩论层、定时任务三处已有能力，用一次高利害决策同时串起来。

### 全库检索确认：这是真空白，不是重复

V0.0.6 及之前的七层里，**「不可逆成本 / 机会成本 / 情绪认知偏差 / 结论反转条件 / 被回避的根本问题」这几个概念一次都没出现过**。具体缺口：

| 提示词 | 补的是什么 |
|---|---|
| 自我觉察 | M2 说「能消除的不重构」，但**没有触发消除的回看动作**；野心层·高度是"把表面任务改成终极结果"，这条是"你连终极结果都没问出口" |
| 重大决策 | 辩论层要多个 AI 互驳、人裁决、保持不偏袒；这条是**单 Agent 三阶段 + 裁决硬度**；「反转条件」把一次性结论变成可监控信号，接得上心法 07 |

## 2. 两处冲突的调和

### 2.1 「全面化身为反方论证专家…」 vs V0.0.3「从不给 AI 设角色」

措辞最直白的一次，但**不冲突，反而是同一条战线**：

- 黄仁勋禁的是「你是某某领域**专家**」这类**抬高权威、拉高讨好属性**的形容词人设；
- 这条要的是**论证方向的功能位**，且自带两道反讨好硬约束：**「禁止支持我」**、**「拒绝强行五五开」**——它在**压**讨好属性，不是放纵。

调和写法：三个**论证位**（反方位 / 支持位 / 裁判位），每个位只写**输出契约**（例：反方位只允许输出反驳条目，禁止任何支持性语句）。槽位 ID 不是人设形容词；校验器查的是条目与措辞，从不查"像不像专家"。

> **第四次复用同一条逻辑**：V0.0.4「不演专家」→ V0.0.5「职责契约 ≠ 人设」→ V0.0.6「审查镜头 ≠ 人设」→ V0.0.7「论证位 ≠ 人设」。**招的是位子，不是演员。**

### 2.2 「裁判直接告诉我哪边占优势」 vs 心法 10 / 辩论层「裁决权在人」

这个是**真差异**，不能糊弄过去：

| | V0.0.3 辩论层 | V0.0.7 决策关 |
|---|---|---|
| 裁决 | 人自己筛选提炼，保持中立不偏袒 | AI 直接给**哪边证据占优**的明确倾向，禁止五五开 |
| 依赖 | 多个 AI / 多个会话互驳 | 单 Agent 内三阶段切换 |

调和后的措辞必须写死：AI 输出的是**证据优势判断 + 最大未知风险 + 反转条件**，**不是替人拍板**。心法 10 仍生效——AI 供给判断，人保留决断权。文档与模板里一律写「哪边证据占优」，不写「替你决定」。

## 3. 实现前提：跨目录扫描（容易被忽略）

提示词 1 说「我们**反复讨论过的所有问题**」，但技能规定「一个对话只干一件事」（心法 08）、「一任务一目录天然隔离」。若不显式做**跨目录扫描**，Agent 只能看到当前任务目录，根本读不到"反复讨论过"，这条提示词会退化成一句空洞反思。

`decision.py scan` 扫 `agent-tasks/*/` 下：

| 数据源 | 提取 | 判为何种信号 |
|---|---|---|
| `progress.md`「决策记录」表第 4 列 | 被否掉的内容 | 跨目录出现 ≥2 次 → **反复被否掉** |
| `findings.md` 含 `[假设]` 的行 | 未验证假设 | 跨目录出现 ≥2 次 → **反复出现的假设** |
| 任务目录名（去掉时间戳前缀） | 同名 slug | 出现 ≥2 次 → **疑似返工** |

> **这也反过来证明：这条提示词只有在三文件体系里才成立**。换个没有落盘记忆的 Agent，问了也白问——它不是新功能，是把心法 09 的价值兑现出来。

若扫描无信号，输出「未发现明显反复模式」，S0 可据此判定"当前问题即真问题"，**不强行制造一个深刻问题**（避免为了交作业而脑补，违反心法 03）。

## 4. 字段规范与闸门规则

`decision.py init` 把 `assets/templates/decision-block.md` **幂等追加**到 `progress.md`（模板本身不内置该区块 → 未触发时零负担）。

| 段 | 必须写什么 | 校验 |
|---|---|---|
| **S0 元层回看** | 4 条：跨会话信号 / 没问出口的更深问题 / 继续·重构·终止 / 回写位置 | 4 条全填实 |
| **S1 反方位** | 6 条：遗漏事实 / 过度乐观假设 / 不可逆成本 / 机会成本 / 最坏风险 / 情绪认知偏差 | 6 条全填实，**且值中不得出现支持性措辞** |
| **S2 支持位** | ≥1 条核心理由 | ≥1 条填实 |
| **S3 裁判位** | 3 条：哪边证据占优 / 最大未知风险 / 人保留决断权 | 全填实；「哪边占优」须含明确倾向（反方 / 支持 / 需补证据 / 暂缓）；**禁和稀泥措辞** |
| **R 反转条件** | ≥1 条「当 X 出现时，结论应反转为 Y」+ 监控方式 | 结构齐全且可观测 |

**禁用词表（脚本层，只查条目值不查字段名）**

- S1 支持性措辞：`建议采纳 / 值得推进 / 应该做 / 利大于弊 / 总体可行 / 我支持 / 赞成这个决定 / 推荐执行 / 不妨做 / 确实更好 / 可以放心 / 完全合理 / 没有明显问题`
- S3 和稀泥：`五五开 / 各有道理 / 难分伯仲 / 不分伯仲 / 见仁见智 / 难分高下 / 势均力敌 / 无法判断哪边 / 持平 / 不分上下`

任何位置残留 `【待填】`、空值、少于 2 字符 → 判未填。区块标记被删 → 判结构损坏。

**启用语义**：区块不存在时 `verify` 默认返回 0 并打印「未启用（按触发条件，属预期）」；显式声明这是高利害决策时加 `--required`，缺区块即返回 1。**触发了才必须有区块，有区块就必须填完。**

## 5. 触发门槛（默认不启用，宁可少用）

满足任一才跑，**消除档 / 轻量档一律跳过**：

- 不可逆成本高：对外承诺、发版、花钱、删数据、签约
- 跨会话反复讨论 ≥2 次，或同一问题返工 ≥2 次
- 用户明确说「我在纠结 / 要不要 / 总觉得哪里不对 / 又绕回来了」
- 方向性选择（做不做、选哪条路），而非执行细节

> 脚本判不出"人是不是在纠结"，所以**触发判断归人/Agent**，`--required` 是把这个判断显式落地的开关。反模式里写死：不得给琐碎任务也跑决策关。

## 6. 与七层的咬合（决策关不新增层）

| 层 | 咬合点 |
|---|---|
| 心法 03 / 05 | S0 无信号时要如实写"无"，不脑补深刻问题；S1 六项是最强形态的 05 证据清单 |
| 心法 06 / M1 | 默认关闭，消除档跳过——**这条是决策关能成立的前提**，否则流程比活重 |
| 心法 07 定时任务 | R 段「监控方式 / 阈值」变成可定时检查的信号，条件命中主动通知 |
| 心法 08 / 09 三文件 | scan 跨目录读决策记录与 `[假设]`；S0 结论回写 `task_plan.md`「3 边界 / 6 变更记录」 |
| 心法 10 | AI 只给证据优势判断，决断权在人 |
| M2 IPO ≤5 / 消除 | S0 若判定「重构目标 / 终止」，就是 M2「能消除的不重构」的触发输入，**回炉砍任务而不是继续优化错的那道题** |
| 沟通层·质量 | 反转条件必须可观测，不写"视情况而定"这类不可核验的话 |
| 辩论层 V0.0.3 | 单人三阶段版；可叠加：决策关 → 送出去多 AI 互驳 → 人裁决 |
| 野心层 V0.0.4 | S0 是高度的**上游**（发现没问出口的终极结果）；R 的反转条件是可证伪的外部观测点，补强深度的外部验证 |
| 帝王团队 V0.0.5 | 组织档下由张良统一跑 S0/S3，避免 3-5 个 AI 各判各的；R 监控交萧何定时查岗 |
| 双闸门层 V0.0.6 | clarify 管**任务内信息缺口**，S0 管**跨会话元层回避**；council 对着**已完成的答案**排雷（交付前），决策关对着**未做的决定**（决策前） |

## 7. Agent 可执行协议

```bash
P=~/.codebuddy/skills/cht-best-skill/scripts

# 0.3 方向定之前 / 4.5 换阶段遇到分叉时，且命中触发门槛才做
python3 $P/decision.py scan "<agent-tasks 的父目录>"     # S0 素材（跨会话信号）
python3 $P/decision.py init "<本任务目录>"               # 幂等追加决策关区块
# 按 assets/prompts/decision.md 填 S0→S1→S2→S3→R
python3 $P/decision.py verify "<本任务目录>" --required || exit 1   # 阻断决策定稿

# 若 S0 判定「重构目标 / 终止」：回写 task_plan.md「3 边界 / 6 变更记录」，回炉用 M2 砍任务
# 交付前照旧：gates.py verify + verify_ambition.py（组织档再 verify_team.py）
```

## 8. 闸门能校验什么、不能校验什么

| 能（结构完整性） | 不能（论证质量） |
|---|---|
| 五段齐全、S1 六项无支持性措辞、S3 有明确倾向且无和稀泥、R 有可观测反转条件、无占位符残留 | 反方够不够强、真问题找得对不对、证据优势判断是不是靠谱 |

纯词表能挡住明显的讨好与和稀泥，挡不住隐晦的偏袒——那靠提示词约束 + 人裁决（心法 10）。做语义级判定要上模型，代价与误判都会上升，V0.0.4 起就没加，这次同样不加。

## 9. 反模式

- 给琐碎任务、单轮问答也跑决策关（违反 M1 与心法 06，流程比活重）
- S0 明明没扫出信号，却硬编一个"深刻问题"交差（脑补，违反 03）
- 模板里预置决策关区块，让它变成每次必过的第六道闸门（把按需扳机做成流程负担）
- 反方位里偷偷夹带「不过总体还是值得做」（讨好回潮，闸门拦截）
- 裁判位写「双方各有道理，难分伯仲」（强行五五开，闸门拦截）
- 让 AI 直接替人拍板「所以你应该做 X」（越过心法 10 的决断权）
- 反转条件写「视情况而定 / 风险变大时」这类不可观测的话（无法接定时任务）
- 只填了 R 段没填 S1/S3，或删掉区块标记绕过校验
- 把决策关的证据优势判断冒充野心层的外部验证标准（自评 ≠ 外部验证）

## 10. 自检三问

1. **选对题**：扫过落盘历史了吗？有没有一个我一直在绕、没问出口的真问题？若真问题变了，我敢不敢**停掉/重构当前任务**？
2. **做对决定**：反方位真的在禁支持的前提下找全了六项吗？裁判位敢不敢**明确说哪边占优**而不和稀泥？
3. **能翻盘**：反转条件是不是可观测、能接定时监控？我是否记得**最终拍板的是我，不是 AI**？
